# Bridge Atelier 用語集 / Terminology

> Bridge Atelierの日本語・英語の対応、読み方、意味を整理した公開用語集の公開候補版です。日本語列は主にドキュメントの標準表記を示し、ゲームUIの表示を拘束しません。

**表記について：** English列は公開ドキュメントの標準表記です。ゲームUIの表示文字列と異なる場合があります。

分類別・関連順に掲載しています。関連する用語は隣接させ、独立した概念は別行で説明します。

## 補足

- **規約の定義とAIの対応：** 規約に定義されていることは、AIがその取り決めをすべて実行できることを意味しません。詳細は[ビディング規約](ja/bidding-system.md)を参照してください。

- **再現性：** SEEDによる配札の再現性は同一ゲームバージョン内に限ります。カードプレイAIの判断は思考レベルによっても変わります（ビディングAIの判断は思考レベルの影響を受けません）。人間のコールやカードによっても以後の展開が変わります。
- **採点：** デュプリケートブリッジの得点表を使用しますが、人間同士のデュプリケート競技の順位付けは行いません。
