## 1. 画面の見方

卓にはノース・イースト・サウス・ウェストの4席があります。人間が参加するモードではサウスを担当し、残りの席をAIが担当します。AI4人の観戦モードもあります。オークション、カードプレイ、局終了後の振り返りで、表示される情報と操作対象が変わります。

- **名札**：各席の名札に席名が表示されます。オークション中と局の終了後は、名札の中に**直近のコール**（その席が最後にしたコール）が表示されます。カードプレイ中は表示されません。
- **状況の表示**：サウスの名札の中央に、いまの状況が表示されます（例：「あなたの番です — ビッドを選んでください」「West が考えています…」「一時停止中（West の番）」）。
- **お知らせ**：操作の結果などの短いお知らせは、画面の中央の列の下部に表示されます。数秒で自動的に消えます。クリックするとすぐに閉じます。

## 2. ゲームの開始

1. Windows版は配布物の案内に従い、Web版は公開ページから起動します。
2. タイトル画面の右上にある［日本語］［English］で、必要なら言語を選びます。
3. ［モード：人間＋AI 3人 ⇄］で、人間がサウスを担当するモードと［AI 4人（自動）］を切り替えます。
4. 配札を再現したい場合は［詳細（研究用）▼］を開き、セットSEEDを入力します。空欄なら自動生成されます。
5. ［4局で開始］［8局で開始］［16局で開始］のいずれかを押すと、**確認画面なしですぐにセットが始まります**。モードとSEEDは先に設定してください。開始時には「4局のセットを始めます。」のようなお知らせが表示されます（セットSEEDは表示されません。第9章）。

**単発の局**：セット開始後、卓のツールバーの［1局だけ遊ぶ］（Windows版はF5）から遊べます。単発の局の成績はセットに含まれません。［セットに戻る（第n局）］で戻れます。単発の局ではモードを切り替えられますが、セット内では切り替えられません。

**タイトルへ戻る**：ツールバーの［セット…］（F2）でセット成績を開き、［タイトルへ］を押します。確認後、進行中のセットは破棄され、再開できません。言語の変更もタイトル画面でのみ可能です。

## 3. オークション

人間の手番で**コール**を選びます。コールにはレベルとスート／ノートランプを指定する**ビッド**のほか、**パス（Pass）**、**ダブル（X）**、**リダブル（XX）**があります。人間の手番では、サウスの名札に「あなたの番です — ビッドを選んでください」と表示されます。最初から4人が連続してPassした場合はパスアウトとなり、カードプレイはありません（確認なしで結果が表示されます）。

**オークション終了の確認**：人間＋AI3人モードでは、契約が決まると、画面の中央の列に「オークション終了」の枠が表示されます。枠には契約とディクレアラー、ダミー、オープニングリードの席が表示され、オークションの経過は左に表示されたままです。［プレイを始める ▶］を押すと（キーボードではEnter）、カードプレイが始まります。押すまではオープニングリードも行われません。AI4人モードとAI卓の表示には、この確認はありません。

市ヶ谷ビディング規約には、コールの意味、保証、義務などの取り決めがあります。規約に定義されたコールでも、AIがすべての経路を実行できるとは限りません。詳細は[ビディング規約](bidding-system.md)へ。

**数値ビッド**は表から選択し、［コール確定］で宣言します（選択中はサウスの名札に「［コール確定］で宣言します」と表示されます）。確定前なら別のビッドを選び直せます。同じビッドをもう一度押すと選択が外れます。

**Pass・Double・Redoubleはボタンを押した瞬間に宣言され、取り消せません。** 合法でないコールは薄く表示され、押せません。規約上の義務によってPassボタンが無効になるわけではありません。

Windows版のキーボード操作：数字1〜7とC／D／H／S／Nでビッドを選びEnterで確定。P＝Pass、X＝Double、R＝Redoubleは即時宣言。Escで選択を解除します。

## 4. ヒント機能

ヒントは**人間＋AI3人モードのオークション中、人間の手番**に、画面の中央の列に表示されます。カードプレイ中には表示されません。

| 設定 | 表示内容 |
|---|---|
| 表示しない（Off） | オークションのヒントを表示しない |
| 規約の意味を表示（Show system meanings） | 規約上の意味や保証などを表示。**初期設定** |
| 規約の意味とAIの推奨を表示（Meanings + AI suggestion） | 規約の意味に加え、AIの推奨を表示 |

**AIの推奨は最適解を保証しません。** 規約の**保証**、**通常目安**、**AIの推定**は異なる概念です。現行UIでは後二者が一括表示される場合があります。ヒントを表示しない設定でも、振り返りでAIの推奨を確認できます。

設定はツールバーの［設定］→［オークションのヒント］から変更でき、オークションの途中でも即座に反映されます。ヒントには次の項目が上から順に表示されます。

| 項目 | 内容 |
|---|---|
| あなたの義務 | 規約上の義務。義務がなければ「なし（Passできます）」。規約上Passできない場面でも、Passの操作はできます |
| Passすると | 自分がPassしたときにオークションがどうなるか |
| 相棒の直前 | パートナーの直前のコールとその意味 |
| これまでの人工ビッド | 相手を含め、これまでに出た人工ビッドとその意味（ある場合だけ） |
| 選択中 | 選んだ数値ビッドの意味・保証・通常目安。選ぶ前は案内文 |
| AIの推奨 | 最上位の設定だけ。AIの推奨するコール（最適とは限りません） |
| 比較した候補と評価値 | 最上位の設定だけ。AIが比較した候補と評価値 |
| 推奨の理由 | 最上位の設定だけ。残りの領域に表示 |

人工の質問に対する回答は「人工の回答」と表示されます。質問した側が人工の回答を受けた場面では、「あなたの義務」に「最終契約を宣言するか、規約で認められた追加の質問をする」ことが表示されます。各コールの意味は[ビディング規約](bidding-system.md)と[規約の完全リファレンス](bidding-reference.md)を参照してください。

Pass・Double・Redoubleは即時宣言なので、選択状態で意味を確認する操作はありません。

## 5. カードプレイ

オークションで決まった契約に従い、各トリックでカードを出します。リードされたスートのカードを持っていれば、そのスートにフォローする必要があります。

- **人間がディクレアラー**：自分の手札に加え、ダミーの手札から出すカードも人間が判断・選択します。
- **人間がディフェンダー**：人間は自分の席を操作し、AIのパートナーと守ります。
- **人間がダミー**：第6章の操作モードに従います。

自分が操作する番には、サウスの名札に「あなたの番です」または「ダミーの番です（あなたが操作）」と表示されます。カードをクリックして選び、**もう一度クリック**するか［プレイ確定］で出します。設定［カードを1クリックで出す］をオンにすると1クリックで出します。フォローの義務などで出せないカードは灰色で選択できません。**出したカードは取り消せません。**

［直前のトリック］で直前のトリックを見直せますが、自分の側が次のトリックにカードを出した後は、局が終わるまで見直せません。Windows版は←→で出せるカードを選び、Enterで出し、Escで選択を外せます。人間がディクレアラーならダミーの番にはダミーの手札からカードを選びます。

## 6. AIの操作

人間（サウス）がダミーになった場合、オープニングリードの後にダミーの手が公開された時点で、次のどちらかを選びます。

| 画面の選択肢 | 誰が判断・操作するか |
|---|---|
| ［ディクレアラーを引き受ける］ | ディクレアラーとダミーの両方を人間が判断・操作 |
| ［AIに任せる（観戦）］ | 両方をAIが判断・操作 |

**この選択は局の途中で変更できません。** 人間操作はAIの指示したカードをクリックするだけのモードではありません。

カードプレイ中に人間が操作する席がある場合は、［残りをCPUに任せる］で残りをAIへ委任できます。確認画面が表示され、**一度任せると、その局では人間操作に戻せません**。得点とIMPは人間の成績として計上されます。

AI4人モードや委任後は、ツールバーの［一時停止］［1手進める］［1トリック］［最後まで］で進行を操作できます。人間が操作する席が残っている間、［最後まで］は使えません。

## 7. 振り返り

局が終わると結果（契約・成否・得点）が表示され、［振り返る］で振り返りに進みます。ツールバーの［表示：プレイ ⇄］／［表示：オークション ⇄］（Windows版はTab）で切り替えます。

- **オークション**：履歴のコールを選ぶと、意味・理由・手札・パートナーの推定・候補と評価値を確認できます。人間のコールには実際の宣言と**AIの推奨**が並び、一致・不一致も表示されます。AIのコールはそのAI自身の判断を示します。
- **カードプレイ**：トリック一覧からカードを選び、理由・候補の評価（目標達成率・平均トリック）を確認できます。人間のカードには「参考：AIなら」をその場で計算して表示するため、計算待ちになる場合があります。
- **移動**：Windows版では←→で1手、↑↓で1トリック（4手）移動します。自動再生機能はありません。

オークション表示の要約欄には得点内訳、4席の手札とHCP、配札SEED、AI判断SEEDなどが表示されます。［テキスト出力］は振り返り表示中に使えます（公開版に残すかは未決定）。セット成績の［振り返る］［AI卓を見る］からも各局を開けますが、進行中の局が終わるまで他局は振り返れません。AI4人モードでは局の途中でも判断理由を確認できます。

**画面上の振り返りとファイルの判断ログは別機能**です。Windows版では各局の人間・AIの判断を保存しますが、AI卓の判断は保存しません。Web版は判断ログをファイル保存しません。

## 8. 得点とIMP

本作は**デュプリケートブリッジの得点表（Law 77）**に基づいて各局を採点します。契約レベルとスート／ノートランプ、達成トリック数、ダブル／リダブル、バルネラビリティなどにより得点が決まります。トリック点は契約レベルに対応する分で、最初の6トリックには付きません。オーバートリック、ボーナス、ダウン時の罰点は別に計算します。

- **セット合計点**：各局の得点を合計します（Law 78Cに対応する方式）。
- **IMP比較**：人間＋AI3人のセットでは、同じ配札をAI4人でプレイする**AI卓**との得点差をIMPに換算します（Law 78Bの換算表）。
- **局況**：セット内のディーラーとバルネラビリティはボード番号に従います（Law 2）。

これは**人間同士のデュプリケート競技や順位付けを再現する機能ではありません**。

## 9. セットとSEED

セットは**4・8・16局**です。セットSEEDは、各局の**配札SEED**と**AI判断SEED**を決めます。同じゲームバージョン・同じセットSEEDなら、セットの局数にかかわらず先頭から同じ配札になります。

- **配札SEED**：カードの配札を決めます。単発の局ではディーラーとバルネラビリティも決めますが、セット内ではそれらはボード番号で決まります。
- **AI判断SEED**：ビディングAIとカードプレイAIの判断に使われます。
- **再現性の限界**：異なるゲームバージョン間での一致は保証しません。カードプレイAIの思考レベルや、人間のコール・カードの選択によって以後の展開が変わります。ビディングAIは思考レベルの影響を受けません。

セットSEEDと配札SEEDは符号を含め**15文字以内の整数**を入力できます。自動生成値は1〜2,147,483,646です。セット開始時のお知らせにはセットSEEDは表示されません。進行中のセットのセットSEEDは、セット成績（［セット…］）の［詳細（研究用）▼］を開くと確認できます。

［この配札をやり直す］（F6）で同じ配札を再プレイできます。セットの局では**新しい結果が成績を上書き**し、成績表にやり直し回数が表示されます。セット途中の保存・再開はできません。保存した配札を開くと単発の局になります。

## 10. 設定と保存

ツールバーの［設定］で開きます。変更した設定は**すぐに反映・保存**されます。言語はタイトル画面でのみ変更できます。

| 設定 | 選択肢・説明 |
|---|---|
| CPUの思考レベル | 速い／標準（既定）／じっくり。カードプレイAIの計算量を変更。Web版の初回は「速い」 |
| 進行の速さ | ゆっくり／標準／速い／待たない。進行時の待ち時間を変更 |
| カードを1クリックで出す | オフ（既定：選択後に確定）／オン（クリックですぐ出す） |
| オークションのヒント | 表示しない／規約の意味を表示（既定）／規約の意味とAIの推奨を表示 |
| 詳細設定（研究用） | 配札SEED、AI判断SEED、計算量の表示、データフォルダーなど |

Windows版の保存先は `%LOCALAPPDATA%\AF-Bridge-Claude\` です。［詳細設定（研究用）］→［フォルダーを開く］から開けます。

| 場所 | 内容 |
|---|---|
| `settings.json` | 設定 |
| `SavedDeals/` | 保存した配札（JSON） |
| `Logs/` | 判断ログとセットの記録 |
| `Exports/` | 振り返りのテキスト |

［配札を保存］［配札を開く］（Windows版はCtrl+S／Ctrl+O）で**初期配札**を保存・読み込みできます。読み込んだ配札は単発の局になります。**進行中のセットの保存・再開には対応しません。** 保存先のフォルダー名は公開版で変更する可能性があります。

## 11. Windows版とWeb版

| 機能 | Windows版 | Web版 |
|---|---|---|
| 位置付け | すべての機能 | 主な機能（一部はWindows版だけ） |
| 判断ログ・セット記録のファイル保存 | 対応 | 非対応 |
| 配札・テキストの出力 | ローカルファイル | ブラウザからダウンロード（公開ビルドで動作確認予定） |
| 配札ファイルを開く | 対応 | 非対応（［配札を開く］は薄く表示され、押すと理由が出る）。Web版で保存した配札はWindows版で開ける |
| データフォルダー | ユーザー別フォルダー | なし（設定はブラウザに保存。［フォルダーを開く］は薄く表示され、押すと理由が出る） |
| 設定の保存 | `settings.json` | ブラウザ保存領域を使用する設計。再起動後の保持は未確認 |
| キーボード操作 | F5、F11／Alt+Enter、Ctrl+S、Ctrl+Oなど | ブラウザと競合する一部キーは使用不可 |
| カードプレイAI | 別スレッドで計算 | 画面の合間に計算。重い配札では画面が一時停止することがある |
| AI卓・IMP | 対応 | 対応。ただし比較結果の表示まで時間がかかる場合あり |

Web版はWindows版と同等の永続保存を保証しません。対応ブラウザ、出力動作、性能は公開ビルドで最終確認します。

## 12. 困ったときは

| 状況 | 最初に確認すること |
|---|---|
| コールが選べない | 自分の手番か、現在のコールが有効かを確認。規約上の義務とUI制限は別の場合があります |
| カードが出せない | 自分の手番と、リードされたスートへのフォローを確認 |
| AIの推奨が見えない | オークション中の人間の手番か、ヒント設定を確認。振り返りでは別途確認できます |
| 同じSEEDなのに結果が違う | ゲームバージョン、思考レベル、人間の操作、セット内の局番号を確認 |
| Web版でログが見つからない | 判断ログとセット記録はWeb版ではファイル保存されません |
| 契約が決まったのにカードプレイが始まらない | 中央の「オークション終了」の枠の［プレイを始める ▶］を押すか、Enterを押してください |
| お知らせが場のカードに重なる | お知らせは数秒で消えます。クリックするとすぐに閉じます |
| セットSEEDを確認したい | セット成績の［詳細（研究用）▼］で確認できます |
| Passを押したらすぐ宣言された | Pass・Double・Redoubleは即時確定で、取り消せません |
| 途中で言語を変更したい | タイトル画面でのみ変更可能。戻ると進行中のセットは破棄されます |
| モードを変更できない | セット開始時に確定します。単発の局では変更できます |
| ［最後まで］が使えない | 人間が操作中は使えません。［残りをCPUに任せる］を利用してください |
| 直前のトリックが見られない | 自分の側が次のトリックへカードを出すと、局終了まで見直せません |
| ほかの局を振り返れない | 進行中の局を終了してください |
| Windows版で全画面にしたい | F11またはAlt+Enter |
