# はじめに — Bridge Atelier

[READMEに戻る](../../README.ja.md) · [English](../en/getting-started.md) · [操作マニュアル](user-manual.md)

Bridge Atelierで最初のセットを始めるための短い案内です。詳しい操作や採点は[操作マニュアル](user-manual.md)を参照してください。

## 1. ゲームを起動する

- **Windows版**：GitHub Releasesから配布版を入手し、同梱の案内に従って起動します。
- **Web版**：公開ページをブラウザで開きます。一部の機能はWindows版だけにあります。

配布先は[README](../../README.ja.md)から確認できます。

## 2. タイトル画面でセットを選ぶ

1. 必要ならタイトル画面で表示言語を選びます。言語の変更はタイトル画面で行います。
2. **局数**を4・8・16から選びます。初めてなら4局がおすすめです。
3. **セットSEED**は空欄で構いません。空欄なら自動生成されます。同じゲームバージョン・同じセットSEEDなら、局数にかかわらず先頭から同じ配札になります。
4. 人間が**サウス**を担当するモードを選び、セットを開始します。AI4人の観戦モードもあります。

## 3. オークションを進める

人間の手番でコールを選びます。いまの状況はサウスの名札の中央に表示されます。ヒントは既定で**「規約の意味を表示」**。必要なら設定で「表示しない」または「規約の意味とAIの推奨を表示」に切り替えられます。AIの推奨は最適解を保証しません。

契約が決まると、中央に「オークション終了」の枠が表示されます。契約、ダミー、オープニングリードの席を確認し、［プレイを始める ▶］（キーボードではEnter）を押します。4人ともPassした場合（パスアウト）は、確認なしで結果が表示されます。

## 4. カードをプレイする

［プレイを始める ▶］を押すと、カードプレイが始まります。オークションの結果に従い、カードを選んでプレイします。自分がディクレアラーならダミーのカードも選びます。ディフェンダーならAIのパートナーと協力します。人間がダミーになる場合の操作モードは[操作マニュアル](user-manual.md)で説明します。

## 5. 結果を振り返る

局が終わったらオークション、カードプレイ、得点を確認できます。人間＋AI3人のセットでは、AI4人の比較卓との**IMP比較**も行います。残りの局を進めてセットを完走しましょう。
