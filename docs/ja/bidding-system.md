# 市ヶ谷ビディング規約 — 実戦ガイド

> 規約版 `Ichigaya-v1.1.4` に基づきます。CPUの対応状況は、ビディングAI `Ichigaya-1.8.0`（Bridge Atelier 1.14.6）のものです。

[English](../en/bidding-system.md) · [用語集](../terminology.md) · [完全リファレンス](bidding-reference.md)

## 1. このガイドの使い方

細かな数値・枚数・優先順位を忘れたときの早見表です。規約の全条件・例外は **[Bidding Reference](bidding-reference.md)** に収録しています。

| 区分 | 意味 |
|---|---|
| **保証** | 規約が確定する条件。後の判断でも引き継がれる |
| **通常** | 通常目安。保証ではなく、外れることがある |
| **CPU基準** | CPUが自分のコールを選ぶときの内部基準。公開の保証ではない |

**CPU未対応は規約不採用と同義ではありません。**

| 記号・略語 | 意味 |
|---|---|
| `M` | メジャー（♥／♠） |
| `m` | マイナー（♣／♦） |
| `x` | 任意のスート |
| `5+` | 5枚以上 |
| `HCP` | ハイカードポイント |
| `BAL` | バランス型。本書では1NTの手形 4333・4432・5332（5枚はマイナーのみ） |
| `NF` | ノンフォーシング（新たな応答義務を作らない） |
| `INV` | 招待（ゲームまたはスラムへ） |
| `F1` | 1回フォーシング |
| `GF` | ゲームフォーシング |
| `TO PLAY` | その契約で止める提案 |
| `NT` | ノートランプ |

`NF`・`INV`・`F1`・`GF`・`TO PLAY` の詳しい意味は[2.4 義務・ラベル](#24-義務ラベル)を参照してください。

### 2.3 ステイマン回答

| 系列 | 保証・意味 | 優先順位・例外 |
|---|---|---|
| `1NT–2♣–2♦` | 人工。♥・♠とも **3枚以下** | — |
| `1NT–2♣–2♥` | 人工。♥ **ちょうど4枚** | **両メジャー4枚なら2♥**。♠4枚を否定しない |

1NTオープニングは5枚メジャーを持たないので、回答のメジャーはちょうど4枚です。

### 2.4 義務・ラベル

| 記号 | 意味 |
|---|---|
| `NF` | 新しい応答義務を作らない。**残存する義務は消えない** |
| `INV` | ゲームまたはスラムへの招待。パートナーは断ってよい |
| `F1` | パートナーに1回の有効な応答を求める |
| `GF` | 自陣がゲームに着くまで継続する義務。スラムの義務ではない |
| `TO PLAY` | その契約で止める提案。新しい義務を作らない |
| `R01 / R02` | 非ジャンプ2/1：オープナーが1回再ビッド、ゲーム未満なら応答者にも再ビッド義務 |

## 3. 主要オープニングの読み方

**メジャー5枚、マイナー3枚**が基本の記憶ポイントです。メジャーは長い方から、同長なら♠。マイナーは長い方から、3–3なら♣、4–4以上の同長なら♦です。5枚メジャーがあれば、マイナーの長さや16–18 HCPに関係なく1Mを優先します。1スートのオープニングのHCPは通常13–21で、保証ではありません（12 HCPでの通常のオープニングも禁止しません）。

`1NT = 16–18 / BAL`、`2NT = 22–24`。1NTで許容される5332は **5枚がマイナーの場合だけ**です。19–21 HCPは、1スートのオープニングから強さを示します。

強い自然2（`2♣–2♠`）は自然で、人工2♣ではありません。通常22+ HCPですが、HCPもスートの最低枚数も保証しません。弱い3スート開始（`3♣–3♠`）は最初の数値ビッドのときだけで、宣言スート6+を保証し、通常は7枚中心です。特殊4M（`4♥ / 4♠`）は、パートナーの助けがなくてもゲームを見込める長く強いメジャーを示す自然なオープニングで、弱いプリエンプトではありません。枚数・HCPの公開保証はなく、切り札合意も生じません。応答で定義されているのは直後の4NT（Aの総枚数の質問、[8.2](#82-特殊4mへの4nt質問)）だけです。詳しくは [Reference 3.6](bidding-reference.md#36-特殊4md04)。

## 4. 主要レスポンスと再ビッド

自然な支持、1NT応答、非ジャンプ2/1を中心に使います。1Mへの単純支持（2M）はNF、ジャンプ支持（3M）はINVで、GFではありません。

非ジャンプ2/1のあと、オープナーには再ビッド義務があり、ゲーム未満であれば応答者にも再ビッド義務が残ります。**局所的なNFでR02は解除されません。** ジャンプの新スート（`1♣–2♦` を含む）はGFです。

リバースは、オープナーが第一スートより上位の新しいスートを2レベルで示す自然な再ビッドです。第二スート4+、第一スートの方が長く、F1です。通常17–21 HCPです。

## 5. ノートランプへの応答とステイマン

`1NT–2♣` は人工ステイマンで、F1です。回答は2.3のとおりで、両メジャー4枚なら2♥を答えます。直接の `2♥ / 2♠` は5+の弱い自然応答（NF）で、`2♦` は未定義です。**トランスファーは採用していません。**

ステイマンの回答後の主な継続：

- `1NT–2♣–2♥–2♠`：人工。応答者は♠4+を示し、オープナーの♠4枚の有無を聞く（F1）。オープナーは♠4枚なら `3♠`（自然、NF）、なければ `2NT`（人工、NF）。
- `1NT–2♣–2♦–2♥ / 2♠`：自然、提示メジャー5+、招待以上（F1）。オープナーは3枚支持なら `3M`（自然、NF）、2枚以下なら `2NT`（人工、NF）。
- `1NT–2♣–2♠–3♥`：自然、♥5+、招待以上のゲーム志向（F1）。オープナーは♥3枚なら `4♥`、2枚以下なら `3NT`。

相手が数値ビッドで介入すると、ステイマンの回答義務は取り消されます。相手のDoubleでは、回答義務は残ります。

## 6. フォーシングと義務

`NF` は「いつでもPass可」を意味しません。すでに発生した応答・再ビッド義務は残ります。`F1`、`GF`、質問への回答義務と、2/1の`R01 / R02`は別々に確認してください。GFは自然なゲーム契約の選択などで果たされます。

## 8. 市ヶ谷リフレインと特殊4Mへの4NT質問

どちらも、Aの総枚数を尋ねる人工の質問から始まり、回答のすぐ上でK、さらにQの総枚数を尋ねられる系列です。A/K/Qの**所在**を尋ねる方式ではありません。

### 8.1 市ヶ谷リフレイン（4♣）

最初の数値ビッドとしての `4♣` で開始する人工のA総枚数質問です。♣の枚数は示しません。パートナーには回答の義務があります。

| 系列 | 回答の意味（Aの総枚数） |
|---|---|
| `4♣–4♦` | 0枚または4枚 |
| `4♣–4♥` | 1枚 |
| `4♣–4♠` | 2枚 |
| `4♣–4NT` | 3枚 |

回答は人工で、`4♣` の次の数値ビッドから4段階です。0枚と4枚は同じ `4♦` で、手札と公開情報から一意になる場合だけ区別できます。

質問者は必要に応じてK、Qの**総枚数**を続けて尋ねられます。A回答のすぐ上のビッドがK質問（例：`4♣–4♦–4♥` の `4♥` はサインオフではなくK質問）、K回答のすぐ上がQ質問で、回答は同じ4段階です。**回答のすぐ上は自然な停止ではありません。** 全段階を質問する義務はなく、回答のすぐ上以外の合法な契約を宣言して止められます。Q回答の後に追加の質問はなく、そのすぐ上も最終契約の候補です。詳しい系列は [Reference 10.3](bidding-reference.md#103-質問と回答)。

発動時の愛称は **Ichigaya Fever（市ヶ谷フィーバー）**。CPUは開始・回答・最終契約の選択に対応しています（回答後の契約の評価は簡易な方式です）。

### 8.2 特殊4Mへの4NT質問

特殊4M（`4♥ / 4♠`）のオープニングの直後に、相手の介入がなく、パートナーが最初のビッドとして宣言する `4NT` は、オープナーの**Aの総枚数**を尋ねる人工の質問（F1）です。切り札合意の後のプレーン・ブラックウッドや、自然NTの文脈の量的4NTとは別のものです。4Mの直後に相手が介入した場合、その4NTはこの質問ではありません（未定義）。

| 回答 | Aの総枚数 |
|---|---|
| `5♣` | 0枚または4枚 |
| `5♦` | 1枚 |
| `5♥` | 2枚 |
| `5♠` | 3枚 |

A回答のすぐ上はK質問、K回答のすぐ上はQ質問で、回答は同じ4段階です。Q回答の後に追加の質問はありません。**回答のすぐ上は自然な停止ではありません**（例：`4♥–4NT–5♦–5♥` の `5♥` はK質問）。質問ではない合法な数値ビッドを宣言すると、それが最終契約（TO PLAY）です。4NT以外の応答・継続は未定義です。K・Qの回答の段階とCPUの契約の選び方は [Reference 9.5](bidding-reference.md#95-特殊4mへの4nt質問)。

### 8.3 人工の回答へのPass

8.1・8.2 の質問者は、回答を受けたら、次の質問か、質問ではない数値ビッド（最終契約）を宣言します。**人工の回答にPassして、その回答を契約にするのは規約外の停止です。**

- 人間の合法なPassは受け付けます。規約違反として記録され、ヒントの「あなたの義務」にも表示されます。
- CPUは規約に従い、人工の回答へのPassで止まりません。
- 切り札が合意されていないので、ブラックウッドの「人工の回答をPassで採用できる」規則は使えません。

### 8.4 相手の介入

| 局面 | 相手の数値ビッド | 相手のDouble |
|---|---|---|
| 人工の質問の回答前 | 回答義務を取り消す | 回答義務を維持する（回答は同じコールで同じ意味） |
| 人工の回答の後、質問者の次の手番まで | 質問の系列が終わり、最終契約の宣言の義務を解除する | 質問の系列と宣言の義務を維持する |

- 回答前の扱い（1行目）は、ステイマン・ガーバー・ブラックウッドなどの人工の質問にも共通です。
- **回答後の扱い（2行目）は、市ヶ谷リフレインと特殊4Mへの4NT質問だけの規定です。** ステイマン、ガーバー、ブラックウッドなどへ広げません。
- 別に発生しているF1・GFなどの義務は、まとめて取り消しません。
- 介入の後の自陣のコールに、新しい意味は付きません（未定義）。人間の合法なコールは、引き続きすべて選べます。
- 詳しくは [Reference 11.3](bidding-reference.md#113-人工の質問への介入)。

## 9. CPU対応状況と注意

**規約上の採用／未定義／不採用／CPU未対応は別概念です。** 例えばジャコビー2NTは規約にありますが、CPUは開始せず、回答・後続も実装していません。`1NT–2♦` は規約で未定義、トランスファーは不採用です。規約にないコールでも競技規則上合法なら、人間は宣言できます。
